# Brainary TUI 使用说明

本文说明当前 Brainary 项目的终端交互界面（TUI），包括基本输入方式、快捷键、公开的斜杠命令和常见操作流程。

图 1：Brainary TUI 交互示例

## 快速开始

在项目目录中启动 TUI：

```bash
cd /path/to/project
brainary
```

也可以在启动时直接提交第一条任务：

```bash
brainary "检查这个项目当前未提交的修改"
```

进入界面后，直接输入任务并按 `Enter` 提交。

## 基本输入方式

| 输入 | 作用 |
| --- | --- |
| 普通文字 | 向 Brainary 提交任务或问题 |
| `/` | 打开内置斜杠命令列表 |
| `@` | 搜索并引用工作区文件 |
| `!` | 执行本地 Shell 命令 |

> `!` 后面的命令会在本机执行。运行删除文件、修改权限、发布或其他不可逆命令前，应先确认目标和影响范围。

## 交互快捷键

- 按 `Enter` 提交当前输入；普通模型任务运行期间，提交的新文字会尝试加入当前轮次。斜杠命令按各自规则执行。
- 任务运行期间按 `Tab` 将普通输入排到下一轮；空闲时提交普通输入。`!` Shell 命令不会通过 `Tab` 提交；PoA 的排队限制见下文。
- 按 `Esc` 中断当前任务或关闭当前弹窗。
- 按 `Ctrl+O` 复制最近一次完成的回复。
- 按 `Ctrl+L` 清空终端显示，但不新建会话。
- 按 `Ctrl+R` 搜索历史输入。
- 按 `Ctrl+T` 打开完整会话记录（transcript）。
- 按 `Ctrl+G` 使用外部编辑器编辑当前输入。
- 按 `Alt+R` 切换便于终端选择和复制的原始滚动模式。
- 按 `Ctrl+/` 在侧边会话与父会话之间切换。

快捷键支持配置和重映射。当前版本的实际绑定以 `/keymap` 显示的内容为准。

## 内置斜杠命令

在输入框中键入 `/` 可查看当前环境展示的命令。下表列出当前公开入口；`/fast` 和 `/plan` 会根据模型能力或功能开关决定是否出现。部分兼容命令只从菜单隐藏，完整输入仍可调用，但不提供菜单候选或前缀补全；已停用的产品入口则不能按这种方式调用。

任务运行期间，多数斜杠命令可用 `Tab` 排到下一轮，届时才打开菜单或执行。PoA 有单独规则：`/poa <PATH>` 和 `/poa fg <PATH>` 可以排队，路径在提交时按当前会话目录确定；`/poa bg <PATH>`、`/poa close` 必须按 `Enter` 直接提交，不能排队。

| 命令 | 作用 | 什么时候使用 |
| --- | --- | --- |
| `/model` | 选择模型和推理强度 | 当前任务需要更快、更强或不同能力的模型时 |
| `/fast` | 开启或关闭当前模型的 Fast 服务档位 | 当前模型支持 Fast 档位，并希望在速度与资源消耗之间切换时 |
| `/keymap` | 查看或重映射 TUI 快捷键 | 默认快捷键冲突，或需要查看当前实际绑定时 |
| `/skills` | 选择用于特定任务的 Skill | 当前任务有对应的专业工作流时 |
| `/rename` | 重命名当前会话 | 需要以后按名称找到当前工作时 |
| `/new` | 在当前 TUI 中开始一个新会话 | 想保留当前终端但开始无关任务时 |
| `/archive` | 归档当前会话并退出 | 暂时收起会话但保留记录时 |
| `/delete` | 永久删除当前会话并退出 | 确认会话及其子会话不再需要时 |
| `/resume` | 恢复已保存的会话 | 继续之前中断的工作时 |
| `/fork` | 从当前或指定会话创建分支会话 | 想尝试另一种方案且不改变原会话时 |
| `/init` | 在当前项目创建包含 Brainary 工作说明的 `AGENTS.md` | 项目还没有持久化协作规则时 |
| `/compact` | 总结旧上下文以释放空间 | 长任务接近上下文上限时 |
| `/plan` | 切换到计划模式 | 希望先确认方案再实施时 |
| `/thread` | 打开会话切换列表 | 在当前会话与其他会话之间切换时 |
| `/poa` | 运行 PoA 包，支持前台、后台运行和关闭后台会话 | 执行已有 PoA 包时；具体写法见下文 |
| `/side` | 从当前上下文临时开启侧边会话 | 想问一个相关小问题但不干扰主会话记录时 |
| `/copy` | 以 Markdown 复制最近一次完成的回复 | 需要把已完成回复粘贴到其他工具时 |
| `/raw` | 切换原始滚动模式 | 终端选择或复制格式化输出不方便时 |
| `/status` | 显示当前会话配置和 Token 使用情况 | 核对模型、权限、工作目录和上下文余量时 |
| `/title` | 配置终端标题显示内容 | 同时打开多个项目或会话，需要从标签快速区分时 |
| `/statusline` | 配置状态栏显示内容 | 希望持续看到模型、分支、Token 或任务进度时 |
| `/theme` | 选择语法高亮主题 | 代码颜色在当前终端不清楚时 |
| `/exit` | 退出 Brainary | 当前工作结束或准备返回 Shell 时 |
| `/clear` | 清空终端并开始一个新会话 | 同时需要清屏和重置对话上下文时 |

`/btw` 和 `/quit` 是可直接输入的别名，不单独出现在默认菜单。`/app`、`/apps`、`/feedback`、`/logout`、`/plugins`、`/usage` 目前不是可用的公开入口。`/delete` 是永久删除操作；如只想暂时收起会话，请使用 `/archive`。

## 运行 PoA 包

PoA（Program of Agent）把程序逻辑、`manifest.toml`、资源及可选的 MCP 服务声明封装成一个可执行包。TUI 接受包目录或 `.poa` 文件；控制程序直接执行，内部调用 Agent 时仍会产生模型请求。

| 写法 | 作用 |
| --- | --- |
| `/poa <PATH>` | 在当前会话前台运行 |
| `/poa fg <PATH>` | 与 `/poa <PATH>` 相同，显式指定前台运行 |
| `/poa bg <PATH>` | 新建后台 PoA 会话运行，当前界面不自动切过去 |
| `/poa close` | 关闭当前查看的后台 PoA 会话；如果其中的 PoA 仍在运行，会先尝试停止它 |

### 前台运行

1. 确认当前会话空闲。
2. 输入 `/poa /path/to/package.poa` 并按 `Enter`。
3. 在当前会话查看输出和完成状态；需要中断时按 `Esc`。

预期结果：PoA 在当前会话执行，结束后可以继续使用 TUI。当前有普通模型任务时，可用 `Tab` 排队，或改用后台运行；如果已有 PoA 在运行，需要先等它结束。

### 后台运行与关闭

1. 输入 `/poa bg /path/to/package.poa` 并按 `Enter`。
2. 使用 `/thread` 切换到对应的 PoA 会话，查看进度和结果。
3. 需要关闭时，在该 PoA 会话中输入 `/poa close` 并按 `Enter`。

预期结果：启动后台 PoA 不会自动切换当前界面。关闭成功后，TUI 移除对应的后台会话入口；这不等同于永久删除历史记录，也不保证后端资源立即全部释放。

### 使用条件与路径规则

- 包目录根部需要有效的 `manifest.toml`，本机需要可用的 code-mode 运行环境。如果报缺少 `codex-code-mode-host`，需要补齐这个配套程序。
- 当前仅支持本地运行；通过 `brainary --remote` 连接远程服务时不能执行 `/poa`，侧边会话中也不能执行。
- `<PATH>` 可使用 absolute path 或相对路径；相对路径按提交命令时当前会话的工作目录解析。
- TUI 不按 Shell 规则处理路径：空格直接保留，不要加引号或反斜杠转义，也不要使用 `~`、环境变量或通配符。例如输入 `/poa /path/to/my package`。
- 同一 TUI 需要等待前一次 PoA 运行结束或取消完成，再启动下一次；“后台”表示另开会话显示，不代表支持同时启动多个 PoA。

从 Shell 或脚本运行时，使用 `brainary poa <PATH>`；旧写法 `brainary exec --poa <PATH>` 仍可用。

## 使用斜杠命令控制会话

以下流程采用与官方参考相同的“操作步骤 + 预期结果”写法。

### 使用 `/model` 切换模型

1. 输入 `/model` 并按 `Enter`。
2. 从弹出的列表中选择模型和可用的推理强度。
3. 使用 `/status` 核对当前模型。

预期结果：Brainary 在会话中确认新的模型选择，后续任务使用该模型。

### 使用 `/fast` 切换 Fast 档位

1. 输入 `/fast` 开启 Fast 档位。
2. 再次输入 `/fast` 将其关闭。

预期结果：Brainary 切换并保存当前模型的服务档位。如果模型目录没有声明 Fast 能力，命令不会显示。

### 使用 `/thread` 切换会话

1. 在输入框中输入 `/thread` 并按 `Enter`。
2. 从列表中选择要查看或继续的会话，包括通过 `/poa bg` 创建的后台 PoA 会话。

预期结果：TUI 切换到选中的会话；这个操作不会创建新会话，也不会删除原会话。旧写法 `/agent` 不再作为使用说明中的命令。

### 用 `/side` 临时讨论

1. 在主会话中输入 `/side <问题>`，也可以使用 `/btw <问题>`。
2. 在侧边会话中完成短问题。
3. 使用 `Ctrl+/` 在侧边会话与父会话之间切换。

预期结果：侧边讨论使用父会话的上下文，但记录与主会话分开，不打断主任务的对话历史。侧边会话中不能再嵌套另一个侧边会话。

### 使用 `/status` 检查当前会话

1. 输入 `/status`。
2. 核对模型、审批策略、沙箱、工作目录和 Token 使用情况。

预期结果：Brainary 打印当前会话摘要，便于确认它正在预期的目录和权限范围内运行。

### 使用 `/archive` 或 `/delete` 整理会话

1. 只想从活跃列表中收起会话时，输入 `/archive` 并确认。
2. 确认会话及其子会话都不再需要时，输入 `/delete` 并确认。

预期结果：`/archive` 保留本地记录并退出；`/delete` 永久删除当前会话及其后代会话并退出。

### 整理当前会话

| 目标 | 使用方式 |
| --- | --- |
| 压缩过长的上下文 | `/compact` |
| 重命名当前会话 | `/rename` |
| 从当前会话创建分支 | `/fork` |
| 切换到其他会话 | `/thread` |
| 临时讨论其他问题 | `/side` |
| 前台运行 PoA | `/poa <PATH>` |
| 后台运行 PoA | `/poa bg <PATH>`，通过 `/thread` 查看 |
| 关闭后台 PoA 会话 | 切换到该会话后执行 `/poa close` |
| 归档并退出 | `/archive` |
| 退出但保留会话 | `/quit` 或 `/exit` |

## 获取帮助

在 TUI 中输入 `/`，可以查看当前平台、配置和功能开关下默认展示的斜杠命令。使用 `/keymap` 可以查看当前快捷键配置。
