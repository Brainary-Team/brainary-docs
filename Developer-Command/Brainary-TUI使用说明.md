# Brainary TUI 使用说明

本文说明如何使用 Brainary 的终端交互界面（TUI），包括基本输入方式、默认快捷键、内置斜杠命令和常见操作流程。

## 快速开始

在项目目录中启动 TUI：

```bash
cd /path/to/project
brainary
```

也可以在启动时直接提交第一条任务：

```bash
brainary "检查这个项目当前未提交的修改"
```

进入界面后，直接输入任务并按 `Enter` 提交。

## 基本输入方式

| 输入 | 作用 |
| --- | --- |
| 普通文字 | 向 Brainary 提交任务或问题 |
| `/` | 打开内置斜杠命令列表 |
| `@` | 搜索并引用工作区文件 |
| `!` | 执行本地 Shell 命令 |

> `!` 后面的命令会在本机执行。运行删除文件、修改权限、发布或其他不可逆命令前，应先确认目标和影响范围。

## 交互快捷键

- 按 `Enter` 提交当前输入；任务运行期间按 `Enter` 会把新指令注入当前轮次。
- 任务运行期间按 `Tab` 将输入排到下一轮；空闲时等同于 `Enter`；输入 `!` Shell 命令时不会提交。
- 按 `Esc` 中断当前任务或关闭当前弹窗。
- 按 `Ctrl+O` 复制最近一次完成的回复。
- 按 `Ctrl+L` 清空终端显示，但不新建会话。
- 按 `Ctrl+R` 搜索历史输入。
- 按 `Ctrl+T` 打开完整会话记录（transcript）。
- 按 `Ctrl+G` 使用外部编辑器编辑当前输入。
- 按 `Alt+R` 切换便于终端选择和复制的原始滚动模式。
- 按 `Ctrl+/` 在侧边会话与父会话之间切换。

快捷键支持配置和重映射。当前版本的实际绑定以 `/keymap` 显示的内容为准。

## 内置斜杠命令

在输入框中键入 `/` 可查看当前环境实际可用的命令。部分命令依赖操作系统、服务能力或功能开关。

任务运行期间输入斜杠命令后按 `Tab`，可以将该命令排到下一轮执行。命令会在轮到它时解析，因此相关菜单或错误提示会在当前任务结束后出现。

| 命令 | 作用 | 什么时候使用 |
| --- | --- | --- |
| `/model` | 选择模型和推理强度 | 当前任务需要更快、更强或不同能力的模型时 |
| `/fast` | 开启或关闭当前模型的 Fast 服务档位 | 当前模型支持 Fast 档位，并希望在速度与资源消耗之间切换时 |
| `/personality` | 选择 Brainary 的沟通风格 | 想改变回复风格，但不想重写任务指令时 |
| `/ide` | 引入 IDE 当前选区、打开文件等上下文 | 希望下一条任务直接引用编辑器现场时 |
| `/permissions` | 设置 Brainary 可以执行的操作范围 | 需要收紧或放宽当前会话的审批和沙箱策略时 |
| `/keymap` | 查看或重映射 TUI 快捷键 | 默认快捷键冲突，或需要查看当前实际绑定时 |
| `/vim` | 开启或关闭输入框的 Vim 模式 | 习惯使用 Vim 编辑方式时 |
| `/setup-default-sandbox` | 设置增强沙箱，仅 Windows 可用 | Windows 提示当前沙箱能力降级并建议重新配置时 |
| `/sandbox-add-read-dir <absolute path>` | 允许沙箱读取额外目录，仅 Windows 可用 | 命令需要读取当前允许范围之外的目录时 |
| `/experimental` | 查看和切换实验性功能 | 明确需要试用尚未稳定的能力时 |
| `/approve` | 批准重试最近一次被自动审查拒绝的操作 | 确认被拒绝的操作合理，希望只重试一次时 |
| `/memories` | 配置记忆的使用和生成 | 需要启用、暂停或调整跨会话记忆时 |
| `/skills` | 选择用于特定任务的 Skill | 当前任务有对应的专业工作流时 |
| `/import` | 从 Claude Code 导入设置、项目和近期会话 | 迁移受支持的外部 Agent 工作环境时 |
| `/hooks` | 查看和管理生命周期 Hook | 检查、信任、禁用或恢复自动执行的 Hook 时 |
| `/review` | 审查当前代码修改并查找问题 | 开发完成后检查回归、风险和缺失测试时 |
| `/rename` | 重命名当前会话 | 需要以后按名称找到当前工作时 |
| `/new` | 在当前 TUI 中开始一个新会话 | 想保留当前终端但开始无关任务时 |
| `/archive` | 归档当前会话并退出 | 暂时收起会话但保留记录时 |
| `/delete` | 永久删除当前会话并退出 | 确认会话及其子会话不再需要时 |
| `/resume` | 恢复已保存的会话 | 继续之前中断的工作时 |
| `/fork` | 从当前或指定会话创建分支会话 | 想尝试另一种方案且不改变原会话时 |
| `/init` | 在当前项目创建包含 Brainary 工作说明的 `AGENTS.md` | 项目还没有持久化协作规则时 |
| `/compact` | 总结旧上下文以释放空间 | 长任务接近上下文上限时 |
| `/plan` | 切换到计划模式 | 希望先确认方案再实施时 |
| `/goal` | 设置、查看或管理长时间任务目标 | 希望 Brainary 在多轮工作中持续追踪同一目标时 |
| `/agent` / `/subagents` | 切换当前活动的 Agent 线程 | 需要查看或继续子 Agent 的工作时 |
| `/side` / `/btw` | 从当前上下文临时开启侧边会话 | 想问一个相关小问题但不干扰主会话记录时 |
| `/copy` | 以 Markdown 复制最近一次完成的回复 | 需要把已完成回复粘贴到其他工具时 |
| `/raw` | 切换原始滚动模式 | 终端选择或复制格式化输出不方便时 |
| `/diff` | 显示 Git 修改，包括未跟踪文件 | 提交前确认 Brainary 实际改了什么时 |
| `/mention` | 搜索并引用文件，与输入 `@` 类似 | 希望后续任务明确聚焦特定文件时 |
| `/status` | 显示当前会话配置和 Token 使用情况 | 核对模型、权限、工作目录和上下文余量时 |
| `/usage` | 查看账户用量或使用用量重置能力 | 已有兼容账户凭据和服务接入，并需要查看额度时 |
| `/debug-config` | 查看配置层及要求来源 | 实际配置与 `config.toml` 预期不一致时 |
| `/title` | 配置终端标题显示内容 | 同时打开多个项目或会话，需要从标签快速区分时 |
| `/statusline` | 配置状态栏显示内容 | 希望持续看到模型、分支、Token 或任务进度时 |
| `/theme` | 选择语法高亮主题 | 代码颜色在当前终端不清楚时 |
| `/mcp` | 列出已配置的 MCP 工具；`/mcp verbose` 显示详情 | 核对外部工具是否启动并可被当前会话调用时 |
| `/apps` | 管理连接器应用 | 当前环境已经接入连接器，并需要把应用加入任务时 |
| `/plugins` | 浏览插件 | 需要查看、启用或发现已配置市场中的插件时 |
| `/quit` / `/exit` | 退出 Brainary | 当前工作结束或准备返回 Shell 时 |
| `/feedback` | 收集反馈和可选日志并调用现有上传链路 | 仅在确认接收方和上传内容后用于排障反馈 |
| `/ps` | 列出后台终端任务 | 检查长时间运行的命令及最近输出时 |
| `/stop` / `/clean` | 停止全部后台终端任务 | 确认不再需要当前会话启动的后台进程时 |
| `/clear` | 清空终端并开始一个新会话 | 同时需要清屏和重置对话上下文时 |

`/fast`、`/personality`、`/plan`、`/plugins` 等命令会根据模型能力或功能开关决定是否显示。`/delete` 是永久删除操作；如只想暂时收起会话，请使用 `/archive`。

`/usage` 依赖兼容账户服务。当前 Brainary 普通账号登录流程已暂停，因此新用户不能假定它可用。

`/feedback` 沿用当前代码中的既有反馈链路，尚不能视为 Brainary 自有反馈渠道。它可能提交与问题相关的运行日志；正式使用前应确认接收端，发送前也要检查上传内容。

## Brainary 项目扩展边界

当前项目提供 PoA（Program of Agent）包执行能力，但此分支的公开入口是 CLI 命令 `brainary exec --poa <PATH>`，TUI 中没有公开的 `/poa` 命令。PoA 的目录格式、限制和示例见《Brainary CLI 使用说明》，不要在 TUI 中把不存在的斜杠命令当作可用功能。

## 使用斜杠命令控制会话

以下流程采用与官方参考相同的“操作步骤 + 预期结果”写法。

### 使用 `/model` 切换模型

1. 输入 `/model` 并按 `Enter`。
2. 从弹出的列表中选择模型和可用的推理强度。
3. 使用 `/status` 核对当前模型。

预期结果：Brainary 在会话中确认新的模型选择，后续任务使用该模型。

### 使用 `/fast` 切换 Fast 档位

1. 输入 `/fast` 开启 Fast 档位。
2. 再次输入 `/fast` 将其关闭。

预期结果：Brainary 切换并保存当前模型的服务档位。如果模型目录没有声明 Fast 能力，命令不会显示。

### 使用 `/personality` 调整沟通风格

1. 输入 `/personality` 并按 `Enter`。
2. 从弹出的列表中选择沟通风格。

预期结果：Brainary 确认新的风格，并在后续回复中使用它。当前模型不支持 personality 指令时，命令不会显示。

### 使用 `/permissions` 调整权限

1. 输入 `/permissions` 并按 `Enter`。
2. 选择符合当前任务风险的审批与沙箱预设。

预期结果：Brainary 显示更新后的策略，后续操作按新策略请求审批并限制资源访问。

### 检查并修改一个项目

1. 在项目目录中运行 `brainary`。
2. 输入任务，例如“检查当前修改，修复测试失败”。
3. Brainary 请求执行命令或修改文件时，检查操作范围和审批提示。
4. 使用 `/diff` 查看工作区修改。
5. 使用 `/review` 再做一次代码审查。
6. 使用 `/status` 查看当前会话配置和 Token 使用情况。

预期结果：修改保留在当前 Git 工作区中；Brainary 不会替你自动提交或发布，除非任务中明确要求并经过相应授权。

### 用 `/goal` 追踪长任务

1. 输入 `/goal <目标>`，例如 `/goal 完成 CLI 换皮并保持测试通过`。
2. 输入 `/goal` 查看当前目标和状态。
3. 使用 `/goal edit` 修改目标，使用 `/goal pause` 或 `/goal resume` 暂停或恢复。
4. 完成后使用 `/goal clear` 清除目标。

预期结果：目标持续绑定到当前会话，Brainary 在多轮工作中继续追踪它。该命令只在相应功能开关启用时显示。

### 用 `/side` 临时讨论

1. 在主会话中输入 `/side <问题>`，也可以使用 `/btw <问题>`。
2. 在侧边会话中完成短问题。
3. 使用 `Ctrl+/` 在侧边会话与父会话之间切换。

预期结果：侧边讨论使用父会话的上下文，但记录与主会话分开，不打断主任务的对话历史。侧边会话中不能再嵌套另一个侧边会话。

### 查看子 Agent 工作

1. 输入 `/agent` 或 `/subagents`。
2. 从列表中选择 Agent 线程。
3. 查看状态、输出，或在该线程中继续交流。

预期结果：TUI 切换到所选 Agent 线程；父会话和其他线程记录仍然保留。

### 使用 `/status` 检查当前会话

1. 输入 `/status`。
2. 核对模型、审批策略、沙箱、工作目录和 Token 使用情况。

预期结果：Brainary 打印当前会话摘要，便于确认它正在预期的目录和权限范围内运行。

### 使用 `/mcp` 检查外部工具

1. 输入 `/mcp` 查看已配置的 MCP 服务和工具。
2. 需要排查连接问题时输入 `/mcp verbose`。

预期结果：TUI 显示当前会话可以调用的 MCP 工具；详细模式同时显示服务状态和诊断信息。

### 使用 `/archive` 或 `/delete` 整理会话

1. 只想从活跃列表中收起会话时，输入 `/archive` 并确认。
2. 确认会话及其子会话都不再需要时，输入 `/delete` 并确认。

预期结果：`/archive` 保留本地记录并退出；`/delete` 永久删除当前会话及其后代会话并退出。

### 整理当前会话

| 目标 | 使用方式 |
| --- | --- |
| 压缩过长的上下文 | `/compact` |
| 重命名当前会话 | `/rename` |
| 从当前会话创建分支 | `/fork` |
| 临时讨论其他问题 | `/side` |
| 归档并退出 | `/archive` |
| 退出但保留会话 | `/quit` 或 `/exit` |

## 获取帮助

在 TUI 中输入 `/`，可以查看当前平台、配置和功能开关下实际可用的斜杠命令。使用 `/keymap` 可以查看当前快捷键配置。
