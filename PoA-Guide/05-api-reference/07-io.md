# IO

IO 函数读取程序的业务输入、向调用方输出结果、向用户提问。用法示例见 [输入与输出](../03-input-output.md)。

以下示例从 `/io` 入口导入，也可以从根入口 `@brainary/poa-sdk` 导入：

~~~js
import { POA_INPUT, ask, audio, image, notify, text, yield_control } from "@brainary/poa-sdk/io";
~~~

### POA_INPUT

**作用**：调用方传入的业务输入，已按包中的 `input_schema.ts` 校验，不需要再解析。

**类型定义**：

~~~ts
const POA_INPUT: JsonValue | undefined;

type JsonValue =
  | string
  | number
  | boolean
  | null
  | JsonValue[]
  | { [key: string]: JsonValue };
~~~

程序在 PoA 中运行时，POA_INPUT 是一个对象；调用方没有传入输入时为 `{}`。TypeScript 中可以断言为 `input_schema.ts` 中的 InputParams 类型，见 [接收输入](../03-input-output.md#接收输入)。

**示例**：

~~~ts
import type { InputParams } from "../input_schema";

const { root, concurrency = 3 } = POA_INPUT as unknown as InputParams;
~~~

### text(value?)

**作用**：向输出追加一段文本。每次调用追加一段，按调用顺序排列。

**输入类型**：value?: unknown。字符串、数字、布尔值、null 和 undefined 转为对应的文本；对象和数组按 `JSON.stringify` 转为 JSON 文本。

**返回值类型**：void。

**异常**：value 无法序列化（如含循环引用）时抛出 TypeError。

**示例**：

~~~js
text("## 扫描结果");
text({ ok: true, count: 3 });  // 输出 {"ok":true,"count":3}
~~~

### image(value, detail?)

**作用**：向输出追加一张图片。

**输入类型**：value: ImageInput；detail?: [ImageDetail](04-message-item.md#imagedetail) | null，传入时覆盖 value 中的 detail。

~~~ts
type ImageInput =
  | string                                              // 图片的 data URI
  | { image_url: string; detail?: ImageDetail | null }  // image_url 为 data URI
  | ImageContent;                                       // MCP image 块

interface ImageContent {
  type: "image";
  data: string;         // base64 数据或 data URI
  mimeType?: string;
  mime_type?: string;
  _meta?: Record<string, unknown>;
}
~~~

[FileExecutor.view_image](05-executors.md#view_imagepath-detail-environment_id) 的结果和 [McpToolResult](05-executors.md#mcptoolresult).content 中的 image 块都可以直接传入。

**返回值类型**：void。

**异常**：图片地址不是 data URI（包括 http、https 地址），或 detail 不是 ImageDetail 的取值时抛出 TypeError。

**示例**：

~~~js
image("data:image/png;base64,iVBORw0KGgo...", "high");
image({ image_url: "data:image/png;base64,iVBORw0KGgo..." });
~~~

### audio(value)

**作用**：向输出追加一段音频。

**输入类型**：value: AudioInput。

~~~ts
type AudioInput =
  | string                  // 音频的 data URI
  | { audio_url: string }   // audio_url 为 data URI
  | AudioContent;           // MCP audio 块

interface AudioContent {
  type: "audio";
  data: string;             // base64 数据或 data URI
  mimeType?: string;
  mime_type?: string;
  _meta?: Record<string, unknown>;
}
~~~

**返回值类型**：void。

**异常**：音频地址不是 data URI 时抛出 TypeError。

**示例**：

~~~js
audio({ audio_url: "data:audio/wav;base64,UklGR..." });
~~~

### yield_control()

**作用**：把已经追加的输出立即交给调用方，程序继续运行。

**输入类型**：无。

**返回值类型**：void。

**示例**：

~~~js
text("开始处理");
yield_control();
~~~

### notify(value?)

**作用**：立即向调用方发送一条进度或状态通知。通知不追加到 text 的输出中。

**输入类型**：value?: unknown，转换规则与 [text](#textvalue) 相同。

**返回值类型**：void。

**异常**：value 转换后为空白文本时抛出 TypeError。

**示例**：

~~~js
notify({ phase: "indexing", completed: 3, total: 10 });
~~~

### ask(request)

**作用**：向用户提出 1–3 个问题，等待回答。

**输入类型**：request: [AskRequest](#askrequest-类型)。

**返回值类型**：Promise<[AskResult](#askresult-类型)>。

| 运行方式 | 结果 |
| --- | --- |
| TUI 前台（`/poa <.poa 文件>`、`/poa fg <.poa 文件>`） | 显示问题，返回 `{ status: "answered", answers }` |
| CLI（`brainary poa`）、TUI 后台（`/poa bg <.poa 文件>`） | 不显示问题，立即返回 `{ status: "unavailable", reason: "nonInteractive" }` |
| Python SDK | 没有 ask，调用时抛出 ReferenceError |

**异常**：

- request 不满足 [AskRequest](#askrequest-类型) 的规则：调用时同步抛出 TypeError。
- TUI 前台运行时，调用 ask 前须 await 所有已发出的 ask、执行器方法和 agent 方法；ask 返回前也不能调用它们，否则抛出错误。

**示例**：

~~~js
const result = await ask({
  questions: [
    {
      question: "部署到哪个环境？",
      options: [
        { label: "staging", description: "预发布环境" },
        { label: "production", description: "生产环境" },
      ],
    },
    { question: "需要补充说明吗？" },
  ],
});

if (result.status === "answered") {
  const [environment, note] = result.answers;
  text({ environment: environment.selected, note: note.text });
} else {
  text({ environment: "staging" });  // 无法提问时使用默认值
}
~~~

### AskRequest 类型

**作用**：ask 的参数。

**类型定义**：

~~~ts
interface AskRequest {
  questions: readonly AskQuestion[];
}

interface AskQuestion {
  question: string;
  options?: readonly AskQuestionOption[] | null;
}

interface AskQuestionOption {
  label: string;
  description: string;
}
~~~

规则：

- questions 有 1–3 个问题。
- question 不能为空白。
- options 省略或为 null 时是自由填写题；提供时是选择题，须有 2–3 个选项，不能是空数组。
- 同一问题的 label 不能重复、不能为空白，不能以 `user_note: ` 开头，也不能是 `None of the above`。
- 每个 question、label、description 不超过 4 KiB，整个 request 序列化后不超过 8 KiB。

### AskResult 类型

**作用**：ask 的返回值。

**类型定义**：

~~~ts
type AskResult =
  | { status: "answered"; answers: AskAnswer[] }
  | { status: "unavailable"; reason: "nonInteractive" };

interface AskAnswer {
  selected: string | null;
  text: string | null;
  rejected?: boolean;
}
~~~

answers 与 questions 按位置一一对应。

| 情况 | selected | text | rejected |
| --- | --- | --- | --- |
| 选择题，选中一个选项 | 选项的 label | 用户附加的备注，没有时为 null | 不存在 |
| 选择题，用户选择 None of the above（以上都不是） | null | 用户附加的备注，没有时为 null | true |
| 自由填写题 | null | 用户填写的内容 | 不存在 |
| 未回答 | null | null | 不存在 |

判断用户是否拒绝了全部选项时检查 `rejected === true`，不要只看 selected 和 text。

**示例**：

~~~json
{
  "status": "answered",
  "answers": [
    { "selected": "production", "text": null },
    { "selected": null, "text": "窗口已审批" }
  ]
}
~~~
