# IO

[IO](08-io.md) 是 PoA 程序与宿主、调用方之间的输入输出边界。

以下示例假定已从 `/io` 入口导入，这些函数也可从根入口 `@brainary/poa-sdk` 导入：

~~~js
import { POA_INPUT, ask, audio, image, notify, text, yield_control } from "@brainary/poa-sdk/io";
~~~

### text(value?)

**作用**：追加文本、数字、布尔值、null 或可序列化 JSON。

**输入类型**：value?: unknown。

**返回值类型**：void。

**示例**：

~~~js
text({ ok: true, count: 3 });
~~~

### image(value, detail?)

**作用**：追加图片内容。

**输入类型**：value: ImageInput；detail?: [ImageDetail](04-message-item.md#imagedetail) | null。

~~~ts
type ImageInput =
  | string
  | { image_url: string; detail?: ImageDetail | null }
  | ImageContent;

interface ImageContent {
  type: "image";
  data: string;
  mimeType?: string;
  mime_type?: string;
  _meta?: Record<string, unknown>;
}
~~~

字符串和 image_url 须为 data URI。ImageContent 即 MCP image 块；MCP 工具返回的 image 块和
[FileExecutor.view_image](05-executors.md#fileexecutor) 的结果都可以直接传入。

**返回值类型**：void。

**示例**：

~~~js
image("data:image/png;base64,...", "high");
image({ image_url: "data:image/png;base64,..." });
~~~

### audio(value)

**作用**：追加音频内容。

**输入类型**：value: AudioInput。

~~~ts
type AudioInput = string | { audio_url: string } | AudioContent;

interface AudioContent {
  type: "audio";
  data: string;
  mimeType?: string;
  mime_type?: string;
  _meta?: Record<string, unknown>;
}
~~~

字符串和 audio_url 须为 data URI；AudioContent 即 MCP audio 块。

**返回值类型**：void。

**示例**：

~~~js
audio({ audio_url: "data:audio/wav;base64,..." });
~~~

### yield_control()

**作用**：把已经累积的输出交给宿主，并继续执行后续程序。

**输入类型**：无。

**返回值类型**：void。

**示例**：

~~~js
text("开始处理");
yield_control();
~~~

### notify(value?)

**作用**：立即发送一条进度或状态通知。

**输入类型**：value?: unknown。

**返回值类型**：void。

**示例**：

~~~js
notify({ phase: "indexing", completed: 3 });
~~~

### POA_INPUT

**作用**：读取调用方传入并通过 schema 校验的业务输入。

**类型定义**：JsonValue | undefined。调用方未传输入时为 `{}`。字段由包的 input_schema.ts 定义，TypeScript 中可断言为 InputParams；
详见 [PoA Input](09-poa-input.md)。

~~~ts
type JsonValue =
  | string
  | number
  | boolean
  | null
  | JsonValue[]
  | { [key: string]: JsonValue };
~~~

**示例**：

~~~js
text(POA_INPUT);
~~~

### ask(request)

**作用**：向用户发送问题并等待答案。

**输入类型**：request: [AskRequest](10-ask.md#函数签名)。

**返回值类型**：Promise<[AskResult](10-ask.md#返回结构)>。

不可交互的运行返回 `{ status: "unavailable", reason: "nonInteractive" }`；交互模式见 [ask()](10-ask.md#模式)。

**示例**：

~~~js
const answer = await ask({ questions: [{ question: "本次检查的重点是什么？" }] });
if (answer.status === "answered") text(answer.answers[0].text);
~~~
