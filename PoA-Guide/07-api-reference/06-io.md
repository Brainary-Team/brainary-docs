# IO

[IO](06-io.md) 是 PoA 程序与宿主、调用方之间的输入输出边界。

### text(value)

**作用**：追加文本、数字、布尔值、null 或可序列化 JSON。

**输入类型**：value: string | number | boolean | null | unknown。

**返回值类型**：void。

**示例**：

~~~js
text({ ok: true, count: 3 });
~~~

### image(value)

**作用**：追加图片内容。

**输入类型**：value: IOValue，通常是图片 data URL、图片对象或宿主内容块。

**返回值类型**：void。

**示例**：

~~~js
image({ image_url: "data:image/png;base64,..." });
~~~

### audio(value)

**作用**：追加音频内容。

**输入类型**：value: IOValue，通常是音频 data URL 或 { audio_url: string }。

**返回值类型**：void。

**示例**：

~~~js
audio({ audio_url: "data:audio/wav;base64,..." });
~~~

### yield_control()

**作用**：把已经累积的输出交给宿主，并继续执行后续程序。

**输入类型**：无。

**返回值类型**：void。

**示例**：

~~~js
text("开始处理");
yield_control();
~~~

### notify(value)

**作用**：异步发送一条进度或状态通知。

**输入类型**：value: unknown。

**返回值类型**：void。

**示例**：

~~~js
notify({ phase: "indexing", completed: 3 });
~~~
